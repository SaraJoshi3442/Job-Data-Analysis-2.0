# 📊 Data Job Analysis 2.0 (Power BI Dashboard)

## Overview
Data Job Analysis 2.0 is an interactive Power BI dashboard designed to analyze trends in the global data job market. The dashboard provides insights into job demand, salaries, skills, job locations, and employment patterns to help job seekers, students, and professionals make informed career decisions.

## Objectives
- Analyze demand for different data-related roles.
- Identify high-paying jobs and salary trends.
- Explore the most in-demand technical skills.
- Compare job opportunities across locations.
- Visualize key employment metrics through interactive dashboards.

## Tools & Technologies
- **Power BI**
- **Power Query**
- **DAX (Data Analysis Expressions)**
- **Data Modeling**
- **Interactive Visualizations**

## Dashboard Features
### 📈 Job Market Overview
- Total job postings
- Distribution of job titles
- Employment type analysis
- Location-based insights

### 💰 Salary Analysis
- Average salary by role
- Salary comparisons across job categories
- High-paying opportunities

### 🛠 Skills Analysis
- Most demanded skills
- Skill frequency distribution
- Relationship between skills and salary

### 🌍 Geographic Insights
- Job availability by location
- Regional hiring trends
- Market demand comparison

### 🎯 Interactive Elements
- Slicers and filters
- Dynamic charts
- Drill-down analysis
- Cross-filtering between visuals

## Key Insights
The dashboard helps answer questions such as:
- Which data roles offer the highest salaries?
- What skills are most valued by employers?
- Where are the most job opportunities located?
- Which technologies appear most frequently in job postings?
